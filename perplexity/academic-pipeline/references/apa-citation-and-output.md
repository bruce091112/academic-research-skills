# APA, Citation & Output Core — Perplexity Edition

This reference preserves paper-formatting and citation-output logic while deferring to current official style and venue instructions when they differ.

## 1. Authority order

When formatting a manuscript, use this precedence:
1. explicit user instructions;
2. target journal/conference/institution instructions;
3. current applicable style manual (e.g., APA 7);
4. this reference as a fallback guide.

Do not override a venue-specific requirement merely because APA would normally format it differently.

## 2. Citation integrity before citation formatting

Formatting does not repair evidential weakness.

Before polishing references:
- confirm the source exists;
- confirm metadata is accurate enough to cite;
- confirm the source supports the nearby claim;
- distinguish primary from secondary citation;
- preserve version/date distinctions that matter.

Never invent missing DOI, page, volume, issue, author, or date fields to make a reference look complete.

## 3. APA 7 fallback principles

When APA 7 is the requested style:
- use author–date in-text citations;
- use `et al.` according to APA rules;
- use `&` in parenthetical citations/reference entries and `and` in narrative prose as appropriate;
- use hanging indents in the reference list;
- use current APA heading hierarchy consistently without skipping levels;
- block-quote longer direct quotations according to APA rules;
- format tables/figures with numbering, titles, and notes according to APA conventions;
- apply bias-free and respectful language guidance.

For unusual source types or uncertain edge cases, verify against current authoritative APA guidance rather than extrapolating.

## 4. Statistics and numbers

Report statistics using the discipline/venue convention. When APA is requested, preserve appropriate notation, confidence intervals, effect sizes, exact p-values when available, and measurement precision.

Do not generate unreported effect sizes or CIs unless explicitly calculated from sufficient supplied data and the derivation is shown.

## 5. Abstract consistency

The abstract must be a compressed representation of the current manuscript, not an independent marketing document.

Before finalizing an abstract:
- verify objective/RQ;
- method/design;
- sample/context if material;
- principal findings;
- limitations/qualifiers needed to avoid overclaim;
- implications within the evidence boundary.

Protected epistemic and scope hedges must survive compression.

## 6. Tables and figures

Do not fabricate values to complete a table or figure.

Every table/figure should have:
- a clear purpose;
- labels that match manuscript terminology;
- units where relevant;
- notes needed to interpret abbreviations/statistics;
- source/adaptation attribution when applicable.

Narrative text and tables/figures must agree on values, direction, sample size, and interpretation.

## 7. Reference-list reconciliation

Before final output:
- every in-text citation should have a corresponding reference entry unless the style explicitly excludes it (e.g., some personal communications);
- every reference-list entry should be cited in the text unless the venue allows a separate bibliography;
- author names, years, titles, and DOI/URL should be internally consistent;
- duplicate work-family entries should be reviewed rather than blindly retained.

## 8. Multilingual / Traditional Chinese manuscripts

For Traditional Chinese academic writing:
- preserve formal written register without translationese;
- use terminology consistently;
- avoid overusing passive constructions imported from English;
- preserve original-language bibliographic data according to the target institution/style;
- do not translate titles, author names, or publication details unless the required style calls for it.

## 9. Output capability boundary

Use the platform's actual available document/export capabilities. Do not assume Pandoc, LaTeX, Word, Python, or local shell tools exist.

When a requested artifact format cannot be produced directly, provide a structurally complete manuscript and clearly identify any remaining formatting/export step rather than claiming the file was generated.

## 10. Final formatting gate

Formatting is last. Verify in this order:
1. research/inference integrity;
2. claim–evidence alignment;
3. RQ/design/findings consistency;
4. citation existence and metadata;
5. cross-document consistency;
6. language/style;
7. target-format details.

Never let cosmetic polish obscure unresolved Critical or Major methodological problems.
